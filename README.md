# The Great Bird War

A solo tactics game about guiding flocks through a short contest for food and territory.

[Play The Great Bird War](https://birdwar.burritoslabs.com/)

## Technology

TypeScript, Phaser and browser-local campaign saves.

## Architecture

The same battle rules support real-time play and pause-to-plan orders. Authored campaign fields, flock identities and environmental hazards shape each scenario.

## Product behavior

Campaigns can save locally. Supported browsers can use offline play, and players can export and import progress.
